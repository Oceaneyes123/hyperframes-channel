# SCRIPT — google-browser-explainer

**Voice:** Supertonic 3 / M1
**Voice settings:** Default English M1 voice; local ONNX inference.
**Voice direction:** Clear, confident, conversational; explain each step without rushing.

---

## Line 1 — Hook (Frame 1)

**Time:** 0.0 – 6.4s
**Delivery:** Curious and inviting.

    You type google.com, press Enter, and your browser begins a tiny trip across the internet.

## Line 2 — Find the numeric address (Frame 2)

**Time:** 6.4 – 13.9s
**Delivery:** Matter-of-fact, with a small pause before the definition.

    But networks do not use names. They need a numeric address—an IP address—to know where to send the request.

## Line 3 — Ask DNS (Frame 3)

**Time:** 13.9 – 25.2s
**Delivery:** Deliberate and guided.

    First, the browser checks what it already knows. If needed, it asks a DNS resolver, which follows the internet's directory—from root, to .com, to Google's records.

## Line 4 — DNS answers (Frame 4)

**Time:** 25.2 – 32.2s
**Delivery:** Crisp reveal.

    A reply comes back with an IP address: the network location the browser can actually contact.

## Line 5 — Open a secure route (Frame 5)

**Time:** 32.2 – 39.6s
**Delivery:** Build anticipation.

    Now the browser opens a connection to that server—and for a site like Google, it needs that route to be secure.

## Line 6 — The HTTPS handshake (Frame 6)

**Time:** 39.6 – 52.6s
**Delivery:** Slow slightly on the three exchanges.

    In the HTTPS handshake, the browser says hello, the server proves its identity with a certificate, and both agree on encryption keys. After that, their messages are private in transit.

## Line 7 — Request the page (Frame 7)

**Time:** 52.6 – 60.5s
**Delivery:** Plain-language explanation.

    With the secure connection ready, the browser sends an HTTP request: essentially, please send me this page.

## Line 8 — Resources return (Frame 8)

**Time:** 60.5 – 70.9s
**Delivery:** Light rhythmic list.

    The server sends back the building blocks: HTML for structure, CSS for appearance, JavaScript for behavior, plus images and fonts.

## Line 9 — Render what you see (Frame 9)

**Time:** 70.9 – 79.6s
**Delivery:** Satisfying, slightly faster toward the reveal.

    The browser reads those pieces, lays them out, paints the pixels, and runs the code. A moment after Enter, the webpage appears.

## Line 10 — The whole trip (Frame 10)

**Time:** 79.6 – 87.4s
**Delivery:** Calm, memorable landing.

    So one address becomes a lookup, a secure conversation, a request, a response, and the page in front of you.
