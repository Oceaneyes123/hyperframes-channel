# How SSH Works

- Workflow: `faceless-explainer`
- Audience: beginners with no prior knowledge of SSH or remote servers
- Format: 1080x1920 portrait; YouTube Shorts / Facebook / Instagram Reels
- Duration: no fixed limit; completeness takes priority over platform runtime
- Takeaway: SSH creates an encrypted connection between a computer and a remote computer, verifies the server, authenticates the user, then carries commands and results securely.
- Captions: off
- Sound effects: off
- Background music: off
- Status: awaiting storyboard/sketch approval

## Scope

Include the client, remote SSH server, `ssh user@server`, TCP port 22 as the common default, handshake, host-key verification, encryption, password and public-key authentication, key placement, command execution, returned output, and the network-observer boundary.

Exclude cryptographic mathematics, detailed cipher negotiation, tunneling/port forwarding, SCP/SFTP, SSH agent forwarding, certificate authorities, and promotional intro/outro.
