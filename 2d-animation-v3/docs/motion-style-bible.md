# Motion style bible: retention experiment

This is an authored direction to test, not a measured reference style or audience result.
Use the existing renderer at 1080 × 1920, 30fps. Keep teaching content within x=80..1000,
y=220..1600; place no essential text under interface controls. Object motion must stay
inside its approved root box. Test final encoded frames at phone size.

## Surface palette

| Treatment | Background | Foreground | Use |
| --- | --- | --- | --- |
| Paper | #F7F3E9 | #203B3A | Object-led explanation |
| Ink | #203B3A | #FFFDF8 | A consequential question or result |
| Mint field | #C6DED3 | #203B3A | Connect adjacent steps |
| Light technical grid | #FFFDF8 | #203B3A | System relationships |
| Warm geometric | #F1D7C7 | #203B3A | Qualitative token/cost comparison |
| Atmospheric ink | #162D30 | #FFFDF8 | Isolate a hero object with restrained halo |

Alternate light/dark only when it clarifies the sequence. Coral #D9633F marks the
thing that changes. A background plane, content plane and foreground token provide
depth; move them at different bounded rates for parallax. Glow is a quiet state
accent, not a flash. Particles appear once around a meaningful result and disappear;
they do not count as an explanation. Maintain one focal action and settled reading holds.

## Objects and scenes

The bundled registry now contains 46 immutable asset identities: 20 existing assets,
20 new original symbols, and six authored scene registry entries. Original pack bytes
are unchanged. New geometry is in workflow/motion-kit.json, built from
scripts/build-motion-assets.ts. Local SVGs and CC0 provenance are under
public/media/motion-kit/. Scene-named SVGs are registry icons; animated artwork is
hand-written in engine/components/trusted-scene.tsx.
The full 46-item set is also exported as individual local SVG files under
public/media/vector-catalog/, with per-item provenance.json. Regenerate that view
using scripts/export-vector-catalog.ts; it reads existing validated nodes without
rewriting the original source packs or changing registered hashes.

The trusted scene entries are message-transform, parallax-workspace,
counted-documents, signal-burst, elastic-token and loop-handoff, each version @1.
They provide geometric object transformation, push/pull parallax, a counter tied to
the three drawn documents, seeded-by-index particles, anticipation/squash/follow-through,
and a position/velocity-matched loop. No arbitrary values or source metrics are accepted.
Use ordinary numeric-display for actual sourced quantities. All geometry comes from
local reviewed source, never model-generated code, SVG strings or URLs.

Use graphic-asset@2 with the exact registered reference. Its reserved motion layer
stores normalized scene time in reveal; scene-play@1 advances 0 to 1 over at least
12 frames. This layer is interpreted by the trusted scene component, not a clipping
mask. It must be visible, unit scale and have zero offsets. The root retains normal
motion/containment rules. Other assets keep their previous reveal semantics.

The recurring character kit is the existing original owner-cutout@1 rig, with neutral,
look, concern, point-laptop, type-laptop and carry-document poses. Preserve its source
hash, anatomy and fixed props; use existing registered rig actions. Reusing it is
preferable to adding a second incompatible character system.

Use no overlay by default; at most one text actor per shot in the 15-second candidate.
An opening physical action should establish the question immediately. Keep the object
or its information visible through the handoff. Explain why a visual changes; motion
variety is a consequence of meaning, not a preset quota.

No third-party media or source code is copied. Remotion commercial eligibility remains
unresolved. Rendered review files do not grant production gates or publication rights.
