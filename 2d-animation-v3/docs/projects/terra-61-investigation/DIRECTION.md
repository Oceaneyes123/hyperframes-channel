## GSAP / Remotion plan

- Remotion owns 30fps frame time and supported overlaps; installed official GSAP adapter interprets validated declarative actions. No timers, random motion, arbitrary selectors, callbacks or executable model graphics.
- Persistent document actor and camera framing provide continuity. Use geometry-matched continuous seams only when the actual source objects match. Use a hard cut into evidence, a purposeful reveal for the cutaway and a supported split-screen only if the comparison remains legible in portrait.
- In a supported semantic diagram, use existing edge-draw/edge-trace beats and destination reaction to expose cause and effect. Check registered part correspondence. Root movement must not detach connectors.
- Plan action, consequence and short comprehension hold. No scene made only of entrance/emphasis/hold. No static hold >4s, camera-only drift, repeated primary presets or decorative motion to satisfy an activity threshold.
- Narration anchor frames above are estimates. After an audition and accepted script, measure line spans, adjust motion to speech, then inspect all scheduled frames and seams. Do not stretch speech to fit these estimates.

## Narration plan

The user specifically prefers a local neural voice after a successful audition. That preference governs this project; no local provider has yet won an audition. Evaluate the existing Qwen3-TTS CustomVoice adapter first for controllable expression, provided its configured runtime/model actually works. Compare a short hook, the number-and-caveat sentence, and the payoff. Keep each take separate and listen to the actual audio before choosing. Chatterbox/Qwen Base remain alternatives only if available and appropriate; installed adapters alone establish no readiness.

Fish Audio audio-version-2 remains the documented channel fallback, subject to this project's voice decision; Windows Speech is a smoke-test option, not an automatic creative choice. Verify runtime availability without downloading a new model or replacing existing audio. Full synthesis follows script acceptance. Provider selection remains pending audible comparison, not a price-based assumption.

Performance: urgent curiosity in hook, impressed clarity in promise, deliberate emphasis on the warnings metric and its conditions, plain explanation for consequence, confident ending. Pronounce GPT, Terra, Codex and 29.6% naturally. Preserve one voice identity; no artificial time stretching. Import measured PCM16 WAV and line spans through existing controls. Listening must check omissions, repetition, pronunciation, pacing and alignment; signal metrics cannot establish expressiveness.
