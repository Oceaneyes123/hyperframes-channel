# Provisional storyboard and visual direction

**Not accepted.** This is a proposed board for the script in [SCRIPT.md](./SCRIPT.md). The three renderer stills are different composition directions, not evidence of a selected concept.

## Three distinct visual directions

1. **Ledger gap:** bright banking UI; current $205, pending $200, available $5 stack as a clear subtraction; a $6 purchase crosses the available line. Calm, explanatory, high legibility.
2. **The terminal moment:** one terminal tap becomes a declined state; the camera pulls back to reveal a separate bank balance. Dark, tactile device close-ups paired with crisp labels.
3. **Two balances, one purchase:** editorial split composition with current and available amounts on opposite sides; the authorization route connects to an issuer decision. High contrast, graphic and diagram-led.

No concept has been chosen. Use the three synthetic PNG files under `.data/card-declined-review-2026-10-26d/` for comparison after the proof script runs.

## Proposed scene order

| Time | Scene and information | Composition / transition |
|---|---|---|
| 0–6s | Ordinary contactless tap; question appears. | Pexels context insert, cropped to terminal/hands only after multi-frame crop review; cut to typographic question. Never associate the person with a decline. |
| 6–13s | Current and available are different measures. | Split-screen balance labels; keep both words visible while the divider opens. |
| 13–22s | $205 current − $200 pending hold = $5 available. | Source-bound numeric displays; animate the equation once, then hold. |
| 22–29s | $6 purchase is greater than $5 available. | Single comparison; one $6 marker crosses the $5 threshold and stops. |
| 29–39s | Merchant → processor/acquirer → network → issuer. | One connected semantic diagram; request travels forward, response returns on the same route. |
| 39–49s | Issuer decides using its rules and account information. | Focus issuer; show “one factor” callout beside the balance, without depicting hidden scoring. |
| 49–59s | Visa code 51 label. | Code card plus clear “Visa table” source label; hold for reading. |
| 59–67s | Visa code 05 is generic. | The same code card resolves to “Do not honor” and “reason not specified”; no fraud imagery. |
| 67–76s | Hold can settle or release; practical next step. | Return to balances, then end on bank app + issuer contact instruction. |

**Readability rule:** no more than one primary numeric comparison per frame; source/network labels remain visible beside code examples; preserve mobile-safe margins and at least a brief settled reading hold. Any cropped source media requires human review before acceptance.
