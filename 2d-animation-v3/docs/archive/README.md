# Historical documentation archive

Original plans, implementation records and completed logs belong here. They are
reference evidence, not current instructions. Agents must not load this archive
by default or recursively follow links. Read a specific historical artifact only
when the user explicitly requests it. Start with [STATUS](../STATUS.md).

Organization is in progress. Source plans currently remain at
[PLAN](../PLAN.md), [PLAN2](../PLAN2.md),
[the supplied advanced-motion original](../../.planning/2026-10-25-advanced-motion-plan/supplied-plan.md)
and [the adapted implementation plan](../ADVANCED-MOTION-IMPLEMENTATION-PLAN.md).
Their approved moves and incoming reference fixes will land together with the
AGENTS read-order change.

Operational scripts, immutable receipts, code-consumed project docs, pinned v2
files and frozen evidence packets keep their current paths until the selected
organization decision can preserve their consumers. No production behavior changes.
