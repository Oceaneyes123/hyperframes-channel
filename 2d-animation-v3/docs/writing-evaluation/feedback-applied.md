## Runtime changes

One shared narration-guidance module applies clarity, conversational progression,
useful examples, restrained disclaimers and a meaningful ending to full drafting,
refinement, editorial review and selected-section requests. Scoped requests remain
confined to their selection; they are not told to force a complete-script ending
into an opening. Claim-ID requirements stay in the annotated full-script contract.

The live revisions exposed a handoff gap: refinement and editorial review lacked
the user's change instructions. Both now receive them. The editor still excludes
the current writer's original draft/private notes and prior verdicts. Original
installed skill files are loaded directly, not rewritten or replaced. No editable
voice-profile UI or automatic approved-example library was added.
