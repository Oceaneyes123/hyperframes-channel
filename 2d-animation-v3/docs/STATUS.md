## Known limitations

- Latest recorded build failed twice: Turbopack CSS worker exited before connecting.
  npm ci reported eight high-severity findings; dependency versions were unchanged.
- Local development is unauthenticated and loopback-only. No automatic source
  retrieval, implicit model/tool download or general voice-quality guarantee.
- Missing ignored databases, models, production inputs and archived media limit
  fresh-clone historical reproduction. The channel Fish reference has no stable
  recorded voice identifier; provider availability was not checked in this audit.
- Synthetic render/seek tests do not establish aesthetic preference, listening
  quality, editing savings or audience outcomes. Preserve failures and raw evidence.
