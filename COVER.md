# Cover image prompt

Use this prompt to generate the static portrait cover for **How HTTPS Actually
Works**. Keep the cover consistent with `DESIGN.md` and the exact local icon art
in `ICON_PLAN.json`.

## Reusable prompt template

> Create a bold, curiosity-driven cover image for a beginner-friendly short
> explainer about **[VIDEO TOPIC]**. Use a **1080×1920, 9:16 portrait** canvas.
>
> Show **[PRIMARY COLORED ICON]** large and immediately recognizable. Optionally
> add just one smaller **[SECONDARY COLORED ICON]** if it makes the relationship
> clearer. Use the supplied local icon assets as-is; do not redraw them. Connect
> the icons only when a simple line helps explain their relationship.
>
> Add this exact headline: **“[2–6 WORD CURIOSITY HEADLINE]”**. Make it the only
> copy. Set it in bold Geist or Space Grotesk, near-white, with strong line
> breaks and enough size to read on a phone. Keep the title and both icons inside
> the project's safe area. Give the title and icon cluster clear separation.
>
> Use the channel's deep navy `#0B1020` background, subtle localized blue or
> indigo light, and restrained route-line detail. Keep the layout simple,
> high-contrast, and icon-first. Make the headline surprising enough to invite a
> click, but accurate to the video. Leave out logos, watermarks, badges, extra
> labels, tiny text, decorative cards, extra icons, and unrelated imagery.
>
> Export one clean PNG at 1080×1920. If exact headline lettering is unreliable,
> generate the icon-and-background artwork without text, then typeset the exact
> headline over it using the channel font and colors.

## Filled prompt for this video

> Create a bold 1080×1920 portrait cover for a beginner-friendly explainer about
> what the lock in a browser actually promises. Use the supplied colored
> Icons8 lock (`public/icons8/lock.png`) as the large focal icon and the supplied
> colored Icons8 server (`public/icons8/server.png`) as the only supporting icon.
> Preserve both assets as-is and connect them with one clean route line. Make the
> lock dominant; let the smaller server hint at the website on the other end.
>
> Set the exact headline **“WHAT IS THAT LOCK FOR?”** in bold, near-white Geist or
> Space Grotesk. Break it into two short lines and make it readable at phone
> size. Use a deep navy `#0B1020` background with restrained blue/indigo light
> and plenty of negative space. Keep the title and icons inside the safe area
> from `DESIGN.md`. Use only these two icons and this headline. No extra labels,
> UI mockups, shields, logos, watermarks, tiny text, or unrelated art. The image
> should create an open question without suggesting that HTTPS makes every site
> trustworthy. Export a clean 1080×1920 PNG.
